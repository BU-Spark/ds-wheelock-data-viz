# WEPC-Research-Visualization
Repository for Data Visualization Project with Wheelock Educational Policy Center and BU Spark!

# Files
## Data
<ul>
  <li>bullying_viz_data.csv: Raw data for all types of bullying</li>
  <li>data_pct_change.csv: Data of percent change over time for all states and bullying types</li>
</ul>

## Code
<ul>
  <li>map_generation.ipynb: Generates US map for percent change data by bullying type</li>
  <li>percent_change.py: Module to convert data to percent change</li>
</ul>

## A Note About Requirements
Requirements.txt is a small list of the dependencies for deploying to Heroku. conda_requirements.txt is a copy of the requirements to make a conda environment, which we recommend using for working on this project. Simply rename conda_requirements.txt to requirements.txt temporarily (make sure to save the original requirements.txt) and use that to create your conda environment, then change the names back.
